  - _Investigated (subagent, stays in Investigate): the "full limit not being used" half is confirmed and located — when a running job goes "lost" it stays in the run queue and intentionally keeps its limit-group token (server.go TTR callback ~1963-2031 sets Lost=true, returns SubQueueRun, no decrement), so it still counts as running and shrinks the usable limit until killed/buried/auto-confirmed-dead (matching the maintainer's diagnosis; a manager restart "fixes" it).
