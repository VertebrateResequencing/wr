# Bugfixes 260628-1

- [x] `make test` and `make race` currently output nothing on success. If it won't
      slow things down noticably or require a major reworking of how things are
      done, have it output the number of passed and skipped tests per test
      function, grouped by pkg with an overall pkg summary, then a final overall
      summary with a nice clear green PASSED. If any tests fail, don't output
      these extra things so we can focus on the existing error messages, but do
      add a clear red FAILED at the end.

  Clarifications from the user (refine the literal request above):
  - Per-function *live/streaming* output is not feasible: lanes run in parallel,
    out of order, with per-lane logs captured to temp files; the summary is
    produced once at the end.
  - Skips are rarely whole test functions. They are overwhelmingly
    `SkipConvey("<english description>", ...)` (GoConvey scope skips; ~25 in the
    tree vs ~6 `t.Skip`). So instead of listing skipped function names, output the
    English string describing what was skipped.
  - Chosen shape: per-package passed/skipped counts ("overall pkg summary"), with
    the English skip descriptions listed under each package; then a final overall
    total; green PASSED on success, red FAILED on failure (failure keeps the
    existing focused error messages).

  Resolution:
  - Lanes now run verbose (`-test.v` for binary lanes, `-v` for go-test lanes in
    `runner.go`); verbose `--- PASS/SKIP:` lines coexist with the existing
    GoConvey JSON blocks, so per-function results and skip descriptions are both
    available without rearchitecting (negligible speed cost — only larger temp
    logs).
  - New `internal/testsuite/runner_summary.go`: pure `summarizeLanes(module,
    inputs, colourize)` builds the success summary (per-package `N passed[, M
    skipped]` sorted by module-relative pkg, English skip descriptions deduped
    with `(xN)`, grand total, `PASSED`). Passed = top-level `--- PASS:`
    functions; skipped = top-level `--- SKIP:` functions + GoConvey scopes with a
    `Skipped:true` assertion (description = scope `Title`; StackTrace ignored).
    Binary lanes attribute to `lane.Package`; go-test lanes segment by
    `ok/FAIL/? <pkg>` delimiters. `summarizeFailureLog`/`stripVerboseNoise`
    strip the added verbose noise on failure (keeping `--- FAIL:`, panics,
    `t.Log`, and GoConvey failure context) and append a red `FAILED`.
  - `reportResults` split into `reportSuccess`/`reportFailure`; colour gated on a
    real TTY via `os.ModeCharDevice` (`isTerminal`), no new dependency. Exported
    `ErrSuiteFailed` sentinel; `cmd/wr-testsuite/main.go` suppresses its
    redundant stderr message (red FAILED is the marker) while still exiting 1 and
    still printing other errors. `planner.go` gained `Plan.Module` to feed
    module-relative package names.
  - Tests: new `runner_summary_test.go` (GoConvey, behavioural — asserts on
    rendered output) covers attribution, both skip kinds, dedup, subtest
    exclusion, totals, colour on/off, and failure noise-stripping. Existing
    `TestFormatLaneLog`/planner tests unchanged.
  - Files: `internal/testsuite/runner_summary.go` (new),
    `internal/testsuite/runner_summary_test.go` (new),
    `internal/testsuite/runner.go`, `internal/testsuite/planner.go`,
    `cmd/wr-testsuite/main.go`. Gates: `make lint` clean, `make test` and
    `make race` exit 0 with the new summary, unit tests pass.
