# Bugfixes 260628-2

These two items are tightly coupled (both are the visual presentation of the
test-suite runner) and share a colour/glyph "style" helper, so they are
implemented and committed together.

- [x] Add an indicator that stuff is happening during a run. Eg. a spinner with
      ephemeral messages when test functions start running.

- [x] Also make your new output more attractive with colours and nicer layout.

  Context / constraints:
  - Builds on 260628-1 (per-package PASSED/FAILED summary in
    `internal/testsuite/runner_summary.go`; lanes run verbose; `isTerminal`,
    `finalMarker`, `summarizeLanes` already exist).
  - Lanes run in parallel and capture combined output to per-lane temp log
    files; the terminal currently shows nothing until the end summary.
  - Must not slow the suite noticeably, must not alter the captured logs or the
    focused failure output, and the ephemeral/colour output must be TTY-gated
    (no spinner bytes or ANSI to pipes/CI/files).

  Resolution:
  - New `internal/testsuite/style.go`: shared `style{rich bool}` helper — ANSI
    colour wrappers (green/yellow/red/cyan/bold/dim, boldGreen/boldRed) and
    Unicode/ASCII glyph accessors. `rich` is true only when the target stream is
    a TTY (`isTerminal`), so piped/CI/file output stays plain and greppable.
    Shared by both the spinner and the summary for consistency.
  - New `internal/testsuite/progress.go`: TTY-gated animated spinner on stderr.
    A 100ms ticker redraws one line (`\r\x1b[2K`, width-truncated via x/term)
    through a compile phase then a test phase showing spinner, tests-started,
    lanes-done/total, and the latest top-level test function. `bypass(w)` erases
    the line before compile output; `tee(w)` writes lane log bytes through
    UNCHANGED while scanning top-level `=== RUN <name>` to feed test names.
    Completely no-op when stderr is not a TTY. Mutex-guarded; -race clean;
    idempotent `stop()` clears the line before the stdout summary; cursor never
    hidden.
  - `runner.go`: progress lifecycle wired into `RunPlan` (start, phase switches,
    bypass around compile, tee + laneStarted/laneFinished in `runLane`, explicit
    stop before `reportResults`); measures wall-clock and threads elapsed through
    to the summary.
  - `runner_summary.go`: beautified summary via `style` — header, marked/aligned
    per-package lines, dim skip descriptions with x N dedup, dim rule, bold grand
    total with elapsed time, glyph+bold-coloured PASSED/FAILED. Same information
    and 260628-1 semantics; plain mode stays ANSI-free.
  - `go.mod`: `golang.org/x/term` promoted to a direct dependency.
  - Tests: new `style_test.go`, `progress_test.go`; updated `runner_summary_test.go`
    for the new format + elapsed; `runner_output_test.go` unchanged. Gates:
    `make lint` clean, `go test -race ./internal/testsuite/` clean, `make test`
    and `make race` exit 0 with the live spinner + coloured summary; off-TTY
    stderr is byte-empty (no spinner/ANSI).
