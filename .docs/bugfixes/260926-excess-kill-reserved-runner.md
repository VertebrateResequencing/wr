Nothing is reserved or counted before the claim, so a refusal leaves no limit group slot or count taken. The post-hand-off `Reserved` call is gone, since the claim already marked the element. An element that claimed but got no job stays marked: its runner is alive and about to exit, killing it gains nothing, and every later reserve claims again under the lock, so leaving it marked can't hand a doomed element a job. Old runners that send no SchedulerID skip the claim, as before.
